# AuraShell — Testing & Demo Guide

## Prerequisites

1. Rust installed (`rustc --version`)
2. A Gemini API key — get one free at [aistudio.google.com](https://aistudio.google.com)
3. macOS or Linux

---

## Setup

```sh
# Navigate to project
cd path/to/AuraShell

# Build
cargo build

# Add your Gemini key to .env
echo 'GEMINI_API_KEY=AIza...' > .env

# Launch AuraShell
./target/debug/msh
```

You should see:
```
~ ❯
```

That prompt means AuraShell is running.

## Test 1 — Basic Shell Commands

**Input:**
```sh
ls -la
```
**Expected:** Directory listing, same as running `ls -la` in any terminal.

---

**Input:**
```sh
echo "Hello from AuraShell"
```
**Expected:**
```
Hello from AuraShell
```

## Test 2 — Pipes

**Input:**
```sh
ls | grep .rs
```
**Expected:** Only `.rs` files printed.

---

**Input:**
```sh
echo "hello world" | wc -w
```
**Expected:**
```
2
```

## Test 3 — Redirection

**Input:**
```sh
echo "test output" > out.txt && cat out.txt
```
**Expected:**
```
test output
```

---

## Test 4 — Conditional Chaining (`&&`)

**Input:**
```sh
mkdir testdir && echo "created"
```
**Expected:**
```
created
```

**Input (failure case):**
```sh
cd nonexistent_dir && echo "this should not print"
```
**Expected:**
```
cd: nonexistent_dir: No such file or directory
```
(second echo is skipped because `cd` failed)

---

## Test 5 — Background Jobs

**Input:**
```sh
sleep 5 &
jobs
```
**Expected:**
```
[1] running   sleep 5
```

## Test 6 — source builtin (load API key)

**Input:**
```sh
echo $GEMINI_API_KEY
```
**Expected:** (blank — not loaded yet)

**Input:**
```sh
source .env
```
**Expected:**
```
source: loaded 1 variable from .env
```

**Input:**
```sh
echo $GEMINI_API_KEY
```
**Expected:** Your actual API key printed.

## Test 7 — AI: Natural Language → Command

> Requires `GEMINI_API_KEY` loaded (run `source .env` first)

**Input:**
```sh
? find all rust source files
```
**Expected:**
```
→  find . -name "*.rs"
[Y/n]:
```
Press `y` — shell runs the command and lists `.rs` files.

---

**Input:**
```sh
? show disk usage of current directory sorted by size
```
**Expected:**
```
→  du -sh * | sort -h
[Y/n]:
```

---

## Test 8 — AI: Error Autopsy

> Requires `GEMINI_API_KEY` loaded

**Input:**
```sh
git pussh origin main
```
**Expected:**
```
git: 'pussh' is not a git command. Did you mean 'push'?
✦ Autopsy: 'pussh' is a typo — run `git push origin main` instead.
```
(Yellow autopsy line is generated by Gemini analyzing the stderr)

---

**Input:**
```sh
cat nonexistent_file.txt
```
**Expected:**
```
cat: nonexistent_file.txt: No such file or directory
✦ Autopsy: The file 'nonexistent_file.txt' does not exist in the current directory. Check the filename or path.
```

---

## Test 9 — Tab Completion

Type the following and press `TAB` (do not press Enter):
```sh
cat REA
```
**Expected:** Auto-completes to `cat README.md`

---

## Test 10 — Ctrl-C behavior

**Input:**
```sh
sleep 30
```
Now press `Ctrl-C`.

**Expected:** `sleep` is killed, shell returns to `~ ❯` prompt. AuraShell itself does NOT exit.

---

## Test 11 — exit

**Input:**
```sh
exit
```
**Expected:** Returns to your normal terminal prompt. History saved to `~/.aura_history`.

## Summary Table

| Feature | Command | Pass Condition |
|---|---|---|
| External command | `ls -la` | Directory listed |
| Pipe | `ls \| grep .rs` | Filtered output |
| Redirection | `echo hi > f.txt && cat f.txt` | `hi` printed |
| Conditional chain | `cd fake && echo yes` | No `echo yes` |
| Background job | `sleep 5 &` then `jobs` | Job listed |
| source builtin | `source .env` | `loaded N variable(s)` |
| NL→command | `? find rust files` | Suggested command shown |
| Error autopsy | `git pussh ...` | Yellow ✦ Autopsy line |
| Tab completion | `cat REA<TAB>` | Completes to README.md |
| Ctrl-C resilience | `sleep 30` + Ctrl-C | Shell stays alive |
